## 🧰 Tecnologias utilizadas no portfólio

Este portfólio foi construído utilizando:

- **React + Vite**
- **JSX**
- **CSS moderno**
- **Framer Motion** *(quando aplicável)*
- **React Icons**

A estrutura base segue o template oficial do Vite:

### React + Vite

Este template fornece uma configuração mínima para iniciar projetos React com Vite incluindo HMR e regras básicas de ESLint.

Atualmente, estão disponíveis dois plugins oficiais:

- [`@vitejs/plugin-react`](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) — utiliza **Babel** para Fast Refresh  
- [`@vitejs/plugin-react-swc`](https://github.com/vitejs/vite-plugin-react-swc) — utiliza **SWC**, oferecendo maior performance  

### Expandindo a configuração ESLint

Para aplicações de produção, recomenda-se o uso de **TypeScript** com regras avançadas do `typescript-eslint`.  
Consulte o modelo oficial:  
https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts
